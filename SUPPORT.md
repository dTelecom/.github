# SDK support

Start with the [SDK catalog](https://docs.dtelecom.org/reference/sdks/) for package names, installation guides and working examples. For an integration question or a reproducible SDK issue, email [dTelecom support](mailto:support@dtelecom.org) with the package version, platform and steps to reproduce. Use the repository issue tracker when it is enabled. For confidential reports, follow the [security reporting policy](https://github.com/dTelecom/.github/blob/main/SECURITY.md).
