# Reporting a security issue

Email [dTelecom support](mailto:support@dtelecom.org) privately with the affected repository or package, its version, and a description of the impact. Include enough detail for a maintainer to investigate. Remove tokens, private keys, personal information and Cloud credentials from logs or attachments.

If a Cloud API key was exposed, revoke it in the dashboard. [Cloud security guide](https://docs.dtelecom.org/platform/security/)
